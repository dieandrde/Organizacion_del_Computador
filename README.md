# Organización del Computador

Repositorio personal de resoluciones de ejercicios, guías y exámenes finales de **Organización del Computador — Cátedra Musso**.

El repositorio está orientado principalmente al análisis de código en **Assembler ARC**, trabajando sobre la arquitectura **ARC/SPARC**, basada en el paradigma **RISC**.

## Contenido

### Guía de ejercicios 4

Resoluciones de ejercicios:

* programación en Assembler ARC
* análisis de instrucciones
* registros y memoria
* subrutinas
* macros
* manejo de la pila
* direccionamiento
* etiquetas y tabla de símbolos
* seguimiento de ejecución

### Exámenes finales

Resoluciones de ejercicios seleccionados de exámenes finales de la materia.

Cada resolución busca mostrar no solamente el resultado final, sino también el proceso utilizado para analizar el código.

Dependiendo del ejercicio, se incluyen:

* código fuente en Assembler ARC
* explicación de las instrucciones
* tabla de seguimiento
* tabla de símbolos
* valores de registros
* valores de memoria
* análisis de saltos y subrutinas
* explicación paso a paso de la ejecución
* resultado final del programa

## Tabla de seguimiento

Las tablas de seguimiento se utilizan para representar la evolución del programa durante su ejecución.

Según el ejercicio, pueden incluir:

* contador de programa
* registros utilizados
* valores de memoria
* instrucciones ejecutadas
* cambios en registros
* flags relevantes

Estas tablas fueron realizadas "a ojo". Como apoyo también se parte del análisis de la ejecución utilizando el simulador correspondiente a la materia.

## Tabla de símbolos

En los ejercicios que utilizan etiquetas, se incluye la correspondiente **tabla de símbolos**, indicando la asociación entre las etiquetas utilizadas en el código y sus direcciones.

Esto permite complementar el análisis de ensamblado y comprender cómo se resuelven las referencias a etiquetas durante el proceso de generación del código.

## Simulador

Los ejercicios de Assembler fueron también trabajados utilizando **ARC Tools**, simulador utilizado para la arquitectura ARC en la materia.

El simulador permite ensamblar y ejecutar los programas, además de observar el estado de los registros y la memoria durante la ejecución.

## Arquitectura

El material de este repositorio se encuentra basado en la arquitectura **ARC/SPARC**, perteneciente a la familia de arquitecturas **RISC**.

Los ejercicios permiten trabajar conceptos como:

* conjunto de instrucciones RISC
* registros
* memoria
* bus del sistema
* ciclo de búsqueda y ejecución
* direccionamiento
* pila
* subrutinas
* instrucciones de salto
* ensamblado
* etiquetas
* código objeto
* tabla de símbolos


La estructura puede variar según el ejercicio, manteniendo como objetivo que cada resolución pueda analizarse de manera independiente.

## Objetivo

Este repositorio funciona como material de estudio y como registro de las resoluciones realizadas durante la cursada.

El foco principal está puesto en **comprender el funcionamiento del código a nivel de máquina**, relacionando el programa en Assembler con el estado de los registros, la memoria y el flujo de ejecución.

> Material realizado con fines académicos y de estudio.
